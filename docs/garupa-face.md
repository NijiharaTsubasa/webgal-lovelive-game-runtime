# BanG Dream 参数表情

`garupa_runtime` 的 `garupa-live2d-face` 为 `motionGroup: "garupa"` 的头身组合提供参数表情适配。宿主采样 Live2D 动作和表情，适配器将通用参数映射到头部已有 Morph、眉片几何与眼部节点。

## 模型数据与能力识别

头部 `morphPoses` 中的 `source.<MapName>` 保存 FaceController 路由对应的 GLB 节点、Morph 与原始目标权重。该权重表达原配方的增益；原生表情按模型的 `expressionGroups` 和配方播放。

适配器在绑定时测量眼部 Morph 的实际位移、闭眼幅度与睫毛开口变化，选择闭眼、笑眼、睁大及眼型基元，并缓存计算结果。

嘴部按原游戏 `AvatarDescription.Id` 所属的角色组选择共同的闭口方向与拉平节点，正向笑口及张口基元使用当前模型的原生增益。转换器将原 `Id` 保存在头部 `Garupa.AvatarScaler` 声明的 `parameters.profile.id`；适配器结合该分组与实际可用 Morph 生成驱动向量。没有对应分组规则时，按当前 Morph 的开口方向筛选保守的通用口型。

眼口参数使用实际 Morph 权重：一个基元指定0.4时，就向对应目标写0.4。各通道可以独立混合。适配器通过 `resolveNode(role, name)` 定位组合后节点，仅修改当前角色实例的权重、眉片几何和节点变换；描边等附加 Pass 沿用渲染器的权重同步。

## 参数映射

| 参数 | 输出 |
| --- | --- |
| `PARAM_EYE_{L,R}_OPEN` | 普通闭眼至正常睁眼；大于1时混合合适的睁大基元 |
| `PARAM_EYE_{L,R}_SMILE` | 睁眼时使用开放笑，闭眼时使用闭笑 |
| `PARAM_EYE_FORM` | 混合模型可用的局部眼形 |
| `PARAM_BROW_{L,R}_X/Y/ANGLE/FORM` | 直接控制眉片的横移、高低、倾角和曲率 |
| `PARAM_MOUTH_OPEN_Y` | 根据通用开合曲线混合模型适合的普通、微笑和负向张口基元 |
| `PARAM_MOUTH_FORM_01` | 在自然中性、负向关键点、自然负端和正向笑口之间连续变化 |
| `PARAM_MOUTH_SCALE` | 嘴部整体尺寸语义；缺少独立尺寸基元时保持原生尺寸 |
| `PARAM_EYE_BALL_X/Y` | 眼球及高光枢轴的注视偏移 |
| `PARAM_EYE_SCALE` | 虹膜末端节点的相对缩放 |
| `PARAM_EYE_HIGHLIGHT` | 高光末端节点的相对缩放 |

嘴部负向曲线使用约 `FORM=-1/3` 的共同拉平关键点。能够自然反弓的模型继续过渡到负端；只有近平或最佳限位形态的模型在关键点后保持该形态。正向使用自然闭笑。口型参数保留超出 `[-1,1]` 的有限值，强负口型在说话时使用较开放的横向椭圆口腔形态，开合为0时仍然闭口。张口时按剩余闭口贡献混合，避免闭口基元覆盖全部开度。原生W唇、细牙缘和小幅耦合按正常观看的表情印象保留。

眉毛使用实例独立的眉片几何。初始化时识别左右眉片及中性轮廓；播放时直接按 `X/Y/ANGLE/FORM` 计算平移、旋转和弯曲。中性参数保留原生眉形，负眉形经过拉平后进入反弓；各参数共同作用于同一眉片。眉片位置依据脸部表面维持遮挡关系，材质和附加 Pass 使用相同的实例几何。关闭参数表情时恢复原生几何和权重，销毁时释放实例副本。

开放笑基元达到完整幅度后，若实际几何变化仍过弱且方向与闭眼相反，绑定时保留该基元，并混入少量原生闭笑基元。补充幅度按模型实际顶点位移标定，普通闭眼和完整闭笑仍使用各自原生端点。

眼部绑定为左右 `Eye_0_0` / `Eye_0_1`，以及每侧三个 `Eye_Hilight_<n>_0` / `Eye_Hilight_<n>_1`。注视参考由身体 Head 当前姿态与原 GLB 中性 Head 姿态共同确定，再换算到各枢轴的父坐标系。当前实例的旋转与缩放作为叠加基准。

## 能力范围与生命周期

原生形变对各参数的支持程度不同，适配器以自然眼口形态、正确开闭及明显情绪方向为先。独立眼褶、嘴部整体上下平移和独立整体缩放没有合适基元时保持原生外观。脸红、眼泪取决于模型已有可驱动效果。没有表情 Morph 的 Michelle 头部保持静态。刘海、服装附件及材质的遮挡取决于模型和对应 Shader。

各目标共用参数解释，不复制来源 Live2D 模型特有的参数限幅。模型原生嘴型、眉弧及幅度可以形成合理的视觉近似。

每帧应用前保存当前原生权重和眼部变换，下一帧开始时恢复；关闭参数表情及销毁适配器时也恢复。眨眼和口型输入由宿主参数播放器合入当前参数，再统一应用一次。原生表情和参数表情通过宿主的外部表情驱动接口交接所有权。

模型能力识别、眉片与脸部表面资料在创建时准备。参数变化时更新眼口 Morph、眉片顶点和眼部节点；眉参数及相关皮肤形变不变时复用眉片结果。
