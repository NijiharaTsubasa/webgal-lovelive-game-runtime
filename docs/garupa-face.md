# BanG Dream 参数表情

`garupa_runtime` 的 `garupa-live2d-face` 为 `motionGroup: "garupa"` 的头身组合提供参数表情适配。宿主使用通用参数播放器采样 Live2D 动作和表情，适配器将当前参数写入头部的原生 Morph 与眼部节点。

## 模型数据

头部 `morphPoses` 中的 `source.<MapName>` 表示 FaceController 的一个底层 BlendShape Map。其 `targets` 保存导出 GLB 节点名、Morph 名及原始 `RangeMax / 100`。同一个 Map 可以作用于眉毛、睫毛和眼皮等多个部件；适配器按各个目标的语义独立驱动它们。

转换器从 Prefab 的 FaceController 导出这些目标，包括未被表情分组引用的 Map。零幅度目标保留零值。同名且目标完全相同的 Map 合并为一项；同名不同目标报错。原生表情使用模型的 `expressionGroups` 和对应配方。

适配器通过宿主的 `resolveNode(role, name)` 定位原始节点，支持加载器清洗显示名称及头身组合后的节点移动。Morph 权重只写入当前角色实例，几何属性保持共享。描边等附加 Pass 使用渲染器的权重同步机制。

## 参数映射

| 参数 | 输出 |
| --- | --- |
| `PARAM_EYE_{L,R}_OPEN` | 对应侧的闭眼形变；原生睁眼形态为上限 |
| `PARAM_EYE_{L,R}_SMILE` | 睁眼时混合 joy，闭眼时在普通闭眼与 wink 之间混合 |
| `PARAM_EYE_FORM` | 在原生 angry 与 sad 眼形间选择方向 |
| `PARAM_BROW_{L,R}_Y` | fun / serious 眉形 |
| `PARAM_BROW_{L,R}_ANGLE` | sad / angry 眉形 |
| `PARAM_BROW_{L,R}_FORM` | joy / kime 眉形 |
| `PARAM_MOUTH_OPEN_Y` | 控制原生嘴部形变的张合幅度 |
| `PARAM_MOUTH_FORM_01` | 控制正负嘴形，在闭口轮廓与笑口、圆口之间连续混合 |
| `PARAM_MOUTH_SCALE` | 在原生幅度内调整张口大小 |
| `PARAM_EYE_BALL_X/Y` | 眼球及高光枢轴的注视偏移 |
| `PARAM_EYE_SCALE` | 虹膜末端节点的相对缩放 |
| `PARAM_EYE_HIGHLIGHT` | 高光末端节点的相对缩放 |

眉部形变系数在组合时归一化，并分别乘以该模型的原始幅度。眉部控制共享原生眉形，因此高低、倾斜与曲率可能互相影响。嘴部使用原 Live2D 参数采样标定的开合曲线。绑定模型时以 A 的形变方向检查候选开口能力，变化过小的 fun / angry 分别采用 A / O；同时从 joy / smile 与 serious / sad / angry 中分别筛选正负闭口轮廓，缺少合适候选时保留中性轮廓。闭口与开口的贡献按剩余权重混合，原控制器的目标幅度参与筛选和最终驱动。这些几何检查只在绑定时运行，用于筛选候选，实际可见轮廓仍需按模型验证。

眼部绑定为左右 `Eye_0_0` / `Eye_0_1`，以及每侧三个 `Eye_Hilight_<n>_0` / `Eye_Hilight_<n>_1`。注视参考由身体 Head 当前姿态与原 GLB 中性 Head 姿态共同确定，再换算到各枢轴的父坐标系。当前实例的旋转与缩放作为叠加基准，偏移幅度采用跨媒介视觉标定。

## 能力范围与生命周期

当前模型的独立形变不足以表示眉毛横向平移与嘴部整体上下平移。在已检查的角色资源、材质绑定及控制路径中，尚未发现可直接驱动的独立眼泪或脸红效果；这些参数保持模型现有外观。`EYELID` 参数暂不映射。没有表情 Morph 的 Michelle 头部保持静态。刘海、服装附件及材质的遮挡仍取决于模型和对应 Shader。

各角色共用嘴部开合曲线。立希原 Live2D 的正向窄白口、小菱形口采用通用笑口近似，轮廓和张口幅度存在可见差异。

每帧应用前保存当前原生权重和眼部变换，下一帧开始时恢复；关闭参数表情及销毁适配器时也恢复。眨眼和口型输入由宿主参数播放器合入当前参数，再统一应用一次。原生表情和参数表情通过宿主的外部表情驱动接口交接所有权。

参数缓存、区域系数及眼部数学对象在创建时分配。每帧执行有限参数读取和 Morph/节点写入；参数不变时复用区域系数。
